** this project is finished **

Tools: Python, FastAPI, sckit-learn, Docker, Joblib

the goal of this project is to analyze the Nvidia stock market history to predict whether NVIDIA's stock will go up or down the next trading day, using historical price/volume data. I started with a notebook with EDA and modeling. logistic regression gave me the best results and I optimized the model but barely increased the accuracy so no need to add optimization to the scripts. this is my first ML end-to-end project. there is a chance I will try to do CI/CD and AWS but it would at a later time since I have to learn and figure out how AWS work.
